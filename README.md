## 📌 Overview

**CitySynapse** is a production-grade Civic Operating System that bridges the gap between **Citizens**, **Field Workforces**, and **Municipal Command Centers**. By transforming disconnected citizen complaints into intelligent, geo-spatial incident clusters with transparent AI triage, CitySynapse empowers municipalities to resolve urban crises with speed, transparency, and accountability.

---

## ✨ Core Pillars & Innovations

### 1. 🤖 Samarth AI Vision & Civic Triage Engine
* **Multilingual NLP**: Accepts citizen complaints in English, Hindi, and regional languages, automatically structuring them into standardized municipal tickets.
* **Photo Fraud Detection**: Detects AI-generated or manipulated images to prevent bogus tickets while gracefully prioritizing authentic field evidence.
* **EXIF GPS Extraction**: Automatically extracts hardware GPS coordinates from photo metadata (with instant fallbacks to device location, interactive map pin, or manual search).
* **Deterministic Department Routing**:
  * 🕳️ **Pothole / Road Crater** ➔ Road Maintenance / PWD
  * 🗑️ **Garbage / Illegal Dump** ➔ Municipal Sanitation Department
  * 🚰 **Sewer Leakage / Overflow** ➔ Water & Sewerage Board

### 2. 📍 Incident Clustering & Explainable Priority Engine
* **Spatial & Temporal Clustering**: Automatically links multiple duplicate citizen reports within 120m into unified clusters (e.g. **Incident Cluster #23**), eliminating ticket backlog inflation.
* **Transparent SLA & Risk Scoring**: Every priority score is fully explainable to operators:
  > *"HIGH PRIORITY — Because: 43 citizen reports · Near Indiranagar School & Metro · Severe two-wheeler accident risk · SLA expires in 42m"*

### 3. ♻️ Circular Ticket-to-Tarmac Pipeline (Plastic Roads)
* Complies with **IRC SP:98** municipal guidelines for plastic-modified bitumen road resurfacing.
* Slices citizen-reported plastic waste directly from garbage dump tickets to provide the 2.36mm shredded polymer modifier for durable, waterproof road repair.

### 4. 🚑 MediRoute Emergency Corridor Integration
* Real-time emergency vehicle routing with dynamic **1.0 km green-wave preemption circles**.
* Overhead Variable Message Sign (VMS) digital billboard integration: *"AMBULANCE IS ON ITS WAY — PLEASE MAKE WAY"*.

### 5. ⭐ Citizen Review & Transparent Resolution Verification
* When a department marks a ticket resolved, citizens can inspect before-and-after photographic evidence.
* Includes a **1–5 Star Rating Picker**, satisfaction status chips (*Satisfied / Partially Satisfied / Not Satisfied*), and transparent feedback recorded on the public civic ledger.

## 🎭 3 Specialized Synchronized Experiences

CitySynapse provides three specialized user interfaces accessible simultaneously via keyboard shortcuts (`1`, `2`, `3`) or the bottom floating dock:

| Experience | Target User | Key Capabilities |
| :--- | :--- | :--- |

| **📱 Citizen App (`2`)** | Everyday Citizens | 20-second reporting flow, voice-to-text dictation, duplicate report alerts, live ticket tracking, and resolution reviews. |

## 🛠️ Technology Stack

* **Frontend**: Vanilla HTML5, CSS3 Modern Glassmorphism, ES6+ Modular JavaScript.
* **Mapping Engine**: Leaflet GIS with Pan-India GeoJSON overlays and Google Maps coordinate integration.
* **Metadata Processing**: Custom zero-dependency binary EXIF 2.31 TIFF GPS parser.
* **Sound Engine**: Synthesized Web Audio API sound effects for operator feedback.
* **Hosting**: GitHub Pages (Continuous Deployment over HTTPS).

## 💻 Local Development Setup

To run CitySynapse locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rrahulrawat07/HackX-Team-no-040-Void-Coders-.git
   cd HackX-Team-no-040-Void-Coders-
   ```

2. **Start the local server:**
   ```bash
   node server.mjs
   ```

3. **Open in your browser:**
   ```
   http://localhost:8080/
   ```
